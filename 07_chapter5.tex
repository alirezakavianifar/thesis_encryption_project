\chapter{بحث و نتیجه‌گیری}

\section{مقدمه}
در این پژوهش، یک الگوریتم نوین برای رمزنگاری تصاویر رنگی با استفاده از ترکیب سیستم‌های آشوبی سه‌بعدی و مدل‌های آشوبی نمایی (\lr{ECM}) ارائه گردید.

\section{تحلیل و تفسیر نتایج تجربی}
نتایج به‌دست‌آمده از پیاده‌سازی بر روی مجموعه داده \lr{USC-SIPI} نشان می‌دهد:
\begin{enumerate}
    \item \textbf{معکوس‌پذیری:} تصاویر رمزگشایی‌شده کاملاً برابر با تصاویر اصلی هستند (\lr{PSNR} برابر $\infty$).
    \item \textbf{توزیع آماری:} هیستوگرام تصاویر رمزشده یکنواخت بوده و موفقیت الگوریتم در کاهش الگوهای قابل پیش‌بینی را تأیید می‌کند (فرضیه ۵).
    \item \textbf{آنتروپی:} میانگین آنتروپی ۷.۹۷۸۹ بیت نشان‌دهنده امنیت بالای الگوریتم است (فرضیه ۳).
    \item \textbf{همبستگی:} کاهش همبستگی به کمتر از ۰.۰۵٪ بیانگر شکستن ساختار مکانی تصویر است (فرضیه ۲).
\end{enumerate}
